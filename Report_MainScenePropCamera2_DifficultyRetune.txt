WHAT CHANGED
- Legs laid by TIME: floor = landing lock + rolls + cooldowns + deadline + T_human(taps, leg). Boost legs,
  plank gaps (time-spaced by face change), bridge lead-outs, portal runways and obstacle margins use the same rule.
  A 2-roll turn is only offered when the leg has time for it; if only a 2-roll turn keeps clear, the leg before
  is lengthened in place. Every leg is validated (errors logged as [TimeBudget]).
- Speed: hold for 6 legs then exponential to vCap; per-leg changes eased over 0.3 s.
- Input: fire on touch-down, every finger counts, swipe conversion only before the roll starts, a tap within
  0.15 s before a corner is buffered for the next leg (never lost), landing lock 0.03 s, double-tap / swipe
  up-down = flip (two taps still work), no hidden left/right swap.
- Corners decided by the runner's logical face at an exact point (sub-step overshoot carried onto the next leg),
  matching the visual edge; the face lane and chevrons end at that point.
- CLOSE CALL: a correct input up to 0.09 s late (max 3.5 cubes past) still makes the corner / plank. Only the
  minimum rolls count, wrong direction / over-rotation / decoy never rescued, one rescue per leg (per plank).
  The runner whips round the corner edge (0.06 s roll + arc blend), +1 bonus point. Feedback: "+1" pop above the
  runner with "CLOSE!", gold shockwave + sparks, lane flash, chevron flare, screen-edge glow, score punch,
  medium haptic, 35 ms hit-stop (not in boosts).
- Waves per 30-leg portal cycle: RELEASE 1-5 / BUILD 6-20 / PEAK 21-27 (boost on odd cycles, bridge cluster on
  even) / COOL-DOWN. Onboarding cycle: 5-leg boost at 14, teaching decoy, teaching bridge, then a teaching
  multi-plank. Hazard budget + cost caps, no stacking, after a cost>=5 leg the next <=2, breathers, glide legs,
  late-game pattern families, no coin lures on hard legs. Camera turns only into RELEASE / portal-runway zones,
  and portals prefer the current camera yaw.
- Camera: speed zoom cap x1.15, boost zoom x1.15 (0.5 s in / 0.4 s out), set at run time. Runner rim (inverted
  hull, RunnerRim.mat). Chevrons glow steady ("hold") when already on the right face. Trail brightness rides the
  wave phase; small flare on clean corners and on clearing a boost.
